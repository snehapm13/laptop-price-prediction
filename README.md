# 💻 Laptop Price Prediction

A Machine Learning-based web application that predicts laptop prices based on specifications such as brand, model, processor, RAM, storage, GPU, screen size, operating system, and weight.

The application is built using **Python, Pandas, Scikit-learn, and Streamlit** and provides an interactive interface for users to enter laptop specifications and get an estimated price.

## 🚀 Features

* 💻 Laptop price prediction using Machine Learning
* 📊 Data preprocessing and feature engineering
* 🧠 Trained Machine Learning model
* 🎯 Price prediction based on laptop specifications
* 🌐 Interactive Streamlit web application
* 🔐 Login and logout functionality
* 📋 User-friendly input form
* 🎨 Custom CSS and attractive interface
* 🖼️ Laptop images and sidebar navigation

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Laptop-Price-Prediction.git
```

Navigate to the project folder:

```bash
cd Laptop-Price-Prediction
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.

## 📈 How It Works

1. User logs into the application.
2. User enters the laptop specifications.
3. The application processes the input data.
4. The trained Machine Learning model predicts the laptop price.
5. The predicted price is displayed on the screen.

## 🎯 Project Objective

The objective of this project is to demonstrate how Machine Learning can be used to predict laptop prices based on their technical specifications and deploy the model as an interactive web application using Streamlit.
